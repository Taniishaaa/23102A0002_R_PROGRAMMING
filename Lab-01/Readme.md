# R Programming Lab 1 – Air Quality Data Cleaning

## Overview
This repository contains the implementation of **R Programming Lab Assignment 1: Air-Quality Data Cleaning using R**.

The practical uses the **Beijing Multi-Site Air Quality Dataset (Aotizhongxin Station)** to demonstrate missing-data handling, loops, user-defined functions, and error handling in R.

## Tasks Performed
- Imported and inspected the air-quality dataset
- Demonstrated `NA`, `NULL`, and `NaN`
- Generated a missing-value summary
- Handled invalid numerical values (`NaN` and `Inf`)
- Replaced missing numerical values using median imputation
- Replaced missing wind direction (`wd`) using mode
- Implemented error handling using `tryCatch()`
- Compared missing values before and after cleaning
- Generated a missing-value visualization
- Exported the cleaned dataset

- `Tanisha_23102A0002_R_L1.ipynb` – Complete R implementation and outputs
